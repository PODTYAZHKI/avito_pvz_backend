# Avito-PVZ-backend

Реализация API для сервиса ПВЗ в рамках тестового задания на стажера Backend-направления.

## Основные возможности:
- Получение JWT-токена. Либо через эндпоинт `/dummyLogin`, либо через регистрацию `/register` и авторизацию `/login`
- Модератор (moderator) может создавать ПВЗ `/pvz`
- Сотрудник ПВЗ (employee) может создавать приемки товаров, добавлять или удалять товары из них и закрывать приемки


## Стек технологий
- Язык программирования: **Go**
- Веб-фреймворк: **Gin**
- Аутентификация: **JWT**
- База данных: **PostgreSQL**
- Деплой: **Docker & Docker Compose**
- Тестирование: **Testify**
- Линтер: **golangci-lint**
- Логирование: **zerolog**



## Установка и запуск

1. Клонировать репозиторий:
```bash
git clone https://github.com/PODTYAZHKI/avito_pvz_backend && cd avito_pvz_backend
```
2. Запустить сервис:

```bash
docker-compose up
```  

3. Сервис доступен по адресу:
```
http://localhost:8080
```

## API

### Авторизация
- POST `/register` - Регистрация нового пользователя
- POST `/login` - Авторизация пользователя
- POST `/dummyLogin` - Получение тестового токена (для разработки)

### ПВЗ
- POST `/pvz` - Создание нового ПВЗ (только для модераторов)
- GET `/pvz` - Получение списка ПВЗ с фильтрацией и пагинацией

### Приемки
- POST `/receptions` - Создание новой приемки товаров
- POST `/pvz/{pvzId}/close_last_reception` - Закрытие последней открытой приемки

### Товары
- POST `/products` - Добавление товара в текущую приемку
- POST `/pvz/{pvzId}/delete_last_product` - Удаление последнего добавленного товара

## Метрики
Сервис предоставляет следующие метрики Prometheus:
- Общее количество запросов
- Время ответа на запросы
- Количество созданных ПВЗ
- Количество приемок
- Количество добавленных товаров

Метрики доступны по адресу: `/metrics`
